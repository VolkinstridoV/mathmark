# Что менялось

[English](CHANGELOG.md) · [Español](CHANGELOG.es.md)

Все версии и что в них появилось. Те же списки приложение показывает
после обновления.


## 1.0.2 — 2026-07-31

- Правка файла прямо в приложении: голый текст с цветами, проверка на лету, кнопки вставки и слэш-команды
- Сломанные формулы подчёркиваются, пока печатаешь — счётчик внизу ведёт к первой
- Создание файла, не выходя из приложения
- Ссылка для обратной связи в настройках


## 1.0.1 — 2026-07-31

- Опознаватель настольной версии сменён на io.github.volkinstridov.MathMark — этого требует Flathub
- Опознаватель приложения на телефоне и запрос из терминала не изменились


## 1.0 — 2026-07-31

- Первый выпуск: чтение файлов .md с формулами, которые рисует KaTeX, без интернета
- Задачи и темы, у каждой три состояния; отметка меняет ровно один байт
- Папки, оглавление, четыре значка по тому, что внутри файла
- Настольная версия: две колонки, поиск по всем файлам, печать, слежение за папкой
- English, Русский, Español
