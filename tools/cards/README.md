# Как добавить формулу в каталог карточек

Каталог `shared/cards/catalog.json` собирается отсюда, руками его не правят.

* `part1.py` … `part6.py` — сами карточки, разбиты по темам;
* `samples.json` — образцы для тех карточек, у которых их нет прямо в описании;
* `build.py` — собирает всё в один файл и проверяет, что у каждой карточки
  есть образец и уникальный опознаватель.

Одна карточка — словарь:

```python
{"id":"quadratic", "s":"algebra",
 "n": n("Quadratic equation", "Квадратное уравнение", "Ecuación cuadrática"),
 "k": n("quadratic discriminant roots", "квадратное дискриминант корни", "..."),
 "form": r"ax^2+bx+c=0",                     # как выглядит на карточке
 "f": [{"id":"a","l":"a"}, ...],             # поля; t: num | list | expr
 "need": [{"if":"a != 0", "show": r"a \neq 0"}],   # условия, показываются математикой
 "try": {"a":"1","b":"-5","c":"6"},          # образец: заполняет поля и служит проверкой
 "steps": [
   {"tex": r"D = b^2 - 4ac"},                # строка разбора, @имя подставляет значение
   {"set": "D = b**2 - 4*a*c"},              # посчитать и запомнить
   {"set": "...", "keep": True},             # посчитать, но не упрощать
   {"when": "D > 0", "steps": [...], "else": [...]},
 ]}
```

Разбор пишется **одной математикой, без слов**: он не переводится ни на один
язык. Переводятся только название и слова для поиска.

После правки:

```bash
python3 tools/cards/build.py     # пересобрать каталог
python3 tools/check_cards.py     # решить каждую и прогнать все формулы через KaTeX
```
